# HR Employee Analytics Dashboard

### Interactive HR Analytics Dashboard using Microsoft Excel

## 📌 Project Overview

This project presents an interactive HR Employee Analytics Dashboard developed using Microsoft Excel.

The dashboard provides insights into employee demographics, salary distribution, department-wise workforce, employee experience and attrition.

It helps users explore HR data through interactive charts, PivotTables, slicers and timelines.

## 🎯 Project Objectives

- Analyse employee distribution across departments.
- Understand gender and age-group distribution.
- Examine average salary and employee experience.
- Analyse employee attrition.
- Explore workforce patterns across different locations.
- Build an interactive dashboard for HR reporting.

## 🛠️ Tools & Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers and Timelines
- Data Cleaning
- Data Analysis
- Interactive Dashboard Design

## 📊 Dashboard Features

### Key Performance Indicators (KPIs)

- Total Employees
- Average Salary
- Average Age
- Average Experience

- Average Performance

### Visualisations

- Employees by Department
- Gender Distribution

- Location
